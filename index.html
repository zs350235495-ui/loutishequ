MODULE_04 // 客户端调优指南 (CLIENT TUNING & CONFIG)

针对 Clash Meta (Mihomo)、Sing-box、Surge 及 Shadowrocket 的底层内核参数调优指南。

GUIDE-01 Clash Meta (Mihomo) 晚高峰 TCP 缓冲区与 Multipath 优化

在配置文件中显式开启 `tcp-concurrent` 与 `find-process-mode: strict`，并将 DNS 查找策略修改为 `redir-host` 或基于 UDP/H3 的加密 DNS，可降低 30% 以上的握手延迟。 

# Mihomo (Clash Meta) 优化配置片段
dns:
  enable: true
  enhanced-mode: fake-ip
  nameserver:
    - https://1.1.1.1/dns-query
    - https://dns.google/dns-query
experimental:
  quic-go-disable-ecn: false
tun:
  enable: true
  stack: system
  auto-route: true
  auto-detect-interface: true
GUIDE-02 Sing-box 1.9+ 内核 Multipath TCP 与 Hysteria2 拥塞窗口调整

针对无线 Wi-Fi 或高丢包环境，将 Sing-box 的 Hysteria2 协议 `up_mbps` 和 `down_mbps` 参数设置为物理宽带上限的 80%，可大幅缓解因主动拥塞控制导致的丢包惩罚。
